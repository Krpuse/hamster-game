# 🐹 هامستر داش — مغامرة المجرة

لعبة متصفح عربية سريعة ومتجاوبة: اقفز، اجمع الجبن، ارفع طاقة السرعة وتجاوز النيازك.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو فعّل GitHub Pages من **Settings → Pages** واختر فرع `main` ومجلد `/root`.

## التحكم
- `Space` أو النقر/اللمس: قفزة
- قفزة مزدوجة متاحة في الهواء
- أفضل نتيجة تُحفظ تلقائياً في المتصفح

## التحميل
اضغط زر **تحميل اللعبة** داخل اللعبة لتنزيل نسخة ZIP من المشروع، أو استخدم زر **Code → Download ZIP** في GitHub.

المشروع مبني بـ HTML5 Canvas وJavaScript وCSS، ولا يحتاج إلى خادم أو تثبيت.
